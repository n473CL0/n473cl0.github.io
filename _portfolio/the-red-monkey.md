## What it is

The website for The Red Monkey, a pub on Chandos Road in Redland, Bristol. It shows opening hours, contact details and links to the pub's live beer board and social media.

## How it's built

* A static Jekyll site with a custom layout and Sass styles, hosted on GitHub Pages under the pub's own domain.
* **Built for a non-technical owner to maintain:** the opening hours, about text, contact details and links all live in two plain files. The repository includes a step-by-step guide to editing them in the GitHub web editor, with no tools to install. The site rebuilds itself a few minutes after each save.
